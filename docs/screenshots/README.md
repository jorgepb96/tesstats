# Tesstats screenshots

This directory keeps the screenshots used by the project in version control. All images show demo data; they do not contain real vehicle, account, or location information.

## Current gallery

- `01-onboarding.png` to `06-settings.png`: original screenshots displayed in the main project README.
- `gallery/01-summary.png`: current summary screen.
- `gallery/02-more.png`: current secondary navigation screen.
- `gallery/03-customization.png`: dashboard customization.
- `gallery/04-driver-portrait.png`: Driver Display in portrait.
- `gallery/05-driver-landscape.png`: Driver Display in landscape (2622 × 1206).

## App Store drafts

`appstore-iphone-6.5/` contains the complete 6.5-inch iPhone draft set, including the portrait Driver Display. These files are kept here so they can be reviewed and regenerated without depending on temporary simulator exports.

The final files uploaded to App Store Connect can still be prepared separately under `docs/appstore/`, which remains ignored because that directory may contain transient export variants.
