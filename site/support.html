1. Tesstats help

Use the connection checklist below for common setup problems. It covers TeslaMate, secure MQTT, TeslaMateApi, connection fields, and demo mode.

Use the Tesstats issue tracker on GitHub for a reproducible app bug or feature request. Check existing issues first.

2. Quick connection checks

  • Confirm the phone or Mac can reach the server network
  • Check the MQTT host, port, transport, path, username, and password
  • Use MQTT over TLS or secure WebSocket for live data
  • Check that TeslaMateApi opens at the base URL you entered
  • Use the in app connection test for a clear status
  • Check certificate trust and Basic Auth settings
  • Try demo mode to confirm that the interface works without your server

If a self signed certificate fails, confirm that it is current and matches the server you expect. Do not turn off security for a public connection.

3. Help for connected services

Tesla vehicle or account

Use Tesla Support for official account, vehicle, service, warranty, charging, and safety help.

TeslaMate server

Use the TeslaMate documentation and the TeslaMate project for installation, Docker, database, Grafana, MQTT publishing, and server updates.

TeslaMateApi

Use the TeslaMateApi project for API installation and endpoint problems.

TestFlight

Join the Tesstats public beta to install the app through TestFlight. See Apple TestFlight for installation and beta update help.

4. A useful issue report

Include the Tesstats version, device model, operating system version, the screen involved, clear steps, expected result, and actual result. Add a screenshot only after removing personal data.

Say whether you use local MQTT TLS or secure WebSocket. Say whether TeslaMateApi is enabled. Replace server names and addresses with safe examples.
